## Getting Started

### View Locally

1. Clone the repository:
```bash
git clone https://github.com/kushh23/ui-mockups.git
cd ui-mockups
```

2. Open `index.html` in your browser:
```bash
open index.html
# or
python -m http.server 8000
# Then visit http://localhost:8000
```

### Project Structure

```
ui-mockups/
├── index.html          # Main gallery page
├── assets/             # Shared assets (images, fonts, etc.)
├── mlo/                # Media Library Organizer mockups
├── APT/                # APT project mockups
├── titan/              # Titan mockups

```
